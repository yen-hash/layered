# Shared SEO plan: Layered (layeredsg.com) and Carpenters 匠 (carpenters.com.sg)

Status: draft for Yen, 15 Oct 2026. Based on Layered's source code and the public home page of carpenters.com.sg. It has no ranking or traffic data yet: the first job is the Search Console exports in section 6.

## 1. Why this plan exists

Both sites target the same cluster: renovation cost, HDB and BTO renovation, interior design Singapore, a cost calculator and a design style quiz. Two sites owned by the same person competing for the same search results can split clicks and signals, and neither wins. Layered is a directory and learning site; Carpenters is a firm selling its own service. The plan gives each site the searches it is best placed to win.

## 2. Who owns which searches

| Search intent | Owner | Examples |
|---|---|---|
| Ready to hire this firm, or the brand | **Carpenters** | carpenters interior design, interior design company Singapore, HDB / condo / landed / commercial interior design, in-house carpentry |
| Compare and choose, neutral | **Layered** | how to choose an interior designer, interior designer fees, Qanvast alternative, renovation package vs custom, questions to ask a designer |
| Rules, permits and process | **Layered** | HDB renovation permit and rules, CaseTrust and HDB licence, defects liability period, renovation contract, payment schedule |
| Budget and cost, head terms | **One owner: decide in the first review** | renovation cost Singapore, HDB renovation cost, BTO renovation cost |
| Cost, long-tail by home type or trade | **Layered** | 3-room / 4-room / 5-room HDB renovation cost, bathroom and kitchen cost, per-trade costs |
| Design styles and ideas | **Split** | Carpenters: showcase of its own projects by style. Layered: neutral style guides and "designers for this style" pages |
| Free tools | **Both, deliberately different** | see section 4 |

Rule: a head keyword gets exactly one owner. The other site may cover long-tail variants but does not write a competing pillar page.

## 3. Head terms to decide first

Carpenters already has a renovation cost guide and an "encyclopedia"; Layered has cost guides and many cost articles. Pick the owner of "renovation cost Singapore" and "HDB renovation cost" using Search Console data (who already ranks higher, who converts better). The loser keeps its page but retitles it to a narrower angle and links to the winner.

## 4. The tools (calculator, style quiz)

Both sites have a cost calculator and a style quiz. Keep both, but make them different:

- **Carpenters:** its own price ranges and its own packages; the end of the tool leads to a design consultation with Carpenters.
- **Layered:** neutral estimators using published 2026 unit rates (calculator, itemised estimator, budget planner, room planner); the end leads to comparing designers on Layered.
- Use different page titles and H1s, and do not copy text between them.

## 5. Linking and technical rules

- Layered's Carpenters listing links to carpenters.com.sg. Carpenters links to specific Layered guides and tools where useful. No sitewide link blocks or footers that link both ways on every page.
- Carpenters is one of several firms on Layered. Layered does not give it special ranking in directory pages beyond the existing "featured" flag, which should be disclosed.
- Avoid duplicate text. If both sites need the same fact, write it separately.
- Each article or page has one focus keyword on one site. Layered's queue already has unique focus keywords across about 280 articles; the next check is against Carpenters' blog and encyclopedia.

## 6. Data we need (one hour of work)

1. Search Console export, last 16 months, top queries and top pages, for **both** sites.
2. List the queries where **both** sites appear. Mark each with the owner from section 2.
3. For queries where the wrong site ranks, retitle or re-angle that page. Do not delete pages.
4. Compare Carpenters' blog and encyclopedia topics with the Layered queue. Hold back or reword queued Layered articles that clash with a Carpenters pillar (move the queue date or change the focus keyword).

## 7. Layered's own fixes (done in the October 2026 SEO PR)

- Five over-long or repetitive titles and two over-long descriptions fixed.
- Sign-up page set to noindex and removed from the sitemap.
- Six style pages given around 200 more words each of unique content, plus per-style FAQs with schema.
- Sitemap last-updated dates added for the estimator and resources pages.

## 8. Ongoing rhythm

- Monthly: check Search Console for queries where both sites compete; adjust by section 2.
- Quarterly: update the cost figures and "last reviewed" dates on both sites at the same time so they do not contradict each other.
- Before publishing anything for either site: look up the focus keyword in this plan.
